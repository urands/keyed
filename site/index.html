Печатайте вслепую всеми десятью пальцами

KeyEd — бесплатный тренажёр слепой печати для английской QWERTY и русской ЙЦУКЕН. Короткие уроки подстраиваются под вас: новые клавиши открываются, когда освоены предыдущие.

ASDFJKL;

Уроки под вас

Текст собирается из настоящих слов и только из открытых клавиш. Слабые клавиши встречаются чаще.

Полный курс

Буквы, заглавные с Shift другой рукой, знаки препинания, цифры и свободная практика предложениями.

Цель и серия

Дневная цель в минутах, серия дней с заморозками, достижения, личные рекорды и напоминания.

Без интернета

Без регистрации и рекламы. Все данные хранятся на вашем компьютере; в сеть уходит только проверка обновлений.

Как установить

Windows

Запустите KeyEd_…_x64-setup.exe. Установщик не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».

macOS

Откройте .dmg (aarch64 — для Apple Silicon, x64 — для Intel) и перетащите KeyEd в «Программы». Приложение не заверено Apple, поэтому при первом запуске macOS его остановит: откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть». Если macOS пишет, что приложение «повреждено», выполните в Терминале команду: xattr -cr /Applications/KeyEd.app

Linux

AppImage: сделайте файл исполняемым (chmod +x) и запустите. Для Debian и Ubuntu есть пакет .deb.
