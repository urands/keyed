# KeyEd — документация

KeyEd — бесплатное настольное приложение для обучения слепой десятипальцевой печати. Первая версия учит английской раскладке QWERTY и русской ЙЦУКЕН.

«Слепая печать» здесь означает набор текста без взгляда на клавиатуру.

## Состояние на 11.11.2026

Фазы 0 и 1 из [плана реализации](implementation-plan.md) завершены. Можно пройти урок из частых английских слов: текст с курсором, виртуальная клавиатура с зонами пальцев, скорость и точность в реальном времени, пауза, экран результата. Прогресс пока не сохраняется, уроки не подстраиваются под пользователя.

Следующий шаг — фаза 2 (адаптивные уроки). Перед ней нужно выбрать источник английского словаря и проверить его лицензию (задача 2.1).
