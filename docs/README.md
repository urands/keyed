# KeyEd — документация

KeyEd — бесплатное настольное приложение для обучения слепой десятипальцевой печати. Первая версия учит английской раскладке QWERTY и русской ЙЦУКЕН.

«Слепая печать» здесь означает набор текста без взгляда на клавиатуру.

## Состояние на 12.11.2026

Фазы 0–6 из [плана реализации](implementation-plan.md) завершены. Приложение учит английской QWERTY и русской ЙЦУКЕН по полному курсу: буквы, заглавные, пунктуация, цифры, свободная практика. Клавиши открываются по мере освоения, слабые встречаются чаще, у каждой раскладки свой прогресс.

Мотивация (фаза 4): дневная цель, серия дней с заморозками, достижения, рекорды, календарь, напоминания и звуки. Релиз (фаза 6): мастер первого запуска, полный экран настроек, клавиатуры ANSI и ISO, дизайн по макетам, экспорт и импорт данных, установщики для трёх ОС в CI, автообновление, страница загрузки.

Осталось: первый выпуск по тегу версии и ручная проверка сборок на macOS и Linux (задача 6.11). Закрытый тест на 5–10 людях ещё не проведён.
