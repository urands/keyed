# KeyEd — документация

KeyEd — бесплатное настольное приложение для обучения слепой десятипальцевой печати. Первая версия учит английской раскладке QWERTY и русской ЙЦУКЕН.

«Слепая печать» здесь означает набор текста без взгляда на клавиатуру.

## Состояние на 11.11.2026

Фазы 0–3 из [плана реализации](implementation-plan.md) завершены — это MVP для закрытого теста. Приложение учит английской QWERTY и русской ЙЦУКЕН: начинает с клавиш под указательными пальцами, открывает клавиши по мере освоения, перед новой клавишей показывает карточку, чаще даёт слабые клавиши. У каждой раскладки свой прогресс. Прогресс, статистика и настройки сохраняются в SQLite. Есть главная с картой клавиатуры, статистика с графиками и тепловой картой, настройки.

Фаза 4 (мотивация) тоже завершена: дневная цель с кольцом, серия дней с заморозками, 11 достижений с плашками, личные рекорды и сравнение недель, календарь занятий, главный вывод урока, напоминания и звуки.

Закрытый тест на 5–10 людях по плану идёт после фазы 3 и ещё не проведён. Следующая фаза — 5 (полный курс: заглавные, пунктуация, цифры).
