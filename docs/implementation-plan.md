# План реализации

План разбит на фазы. Каждая фаза заканчивается работающим приложением, которое можно показать и проверить. Номера задач (например, 2.3) используются для ссылок в коммитах и обсуждениях.

Связанные документы: [продукт](product.md), [методика](learning-method.md), [экраны](screens.md), [архитектура](architecture.md).

## Обзор

| Фаза | Результат | Оценка |
|---|---|---|
| 0. Каркас | Пустое приложение запускается, работают тесты и CI | 1–2 дня |
| 1. Ядро печати | Экран практики на английском: текст, клавиатура, показатели, результат | 1–1,5 недели |
| 2. Адаптивные уроки | Статистика клавиш, открытие клавиш, сохранение прогресса, экран статистики | 2 недели |
| 3. Русский язык | Раскладка ЙЦУКЕН, русское содержание, русский интерфейс | 1 неделя |
| 4. Мотивация | Дневная цель, серия, достижения, напоминания | 1 неделя |
| 5. Полный курс | Заглавные, пунктуация, цифры, свободная практика | 1 неделя |
| 6. Релиз | Первый запуск, настройки, дизайн, установщики, обновления | 1–2 недели |

Оценки ориентировочные: один разработчик, полный рабочий день. Всего 7–9 недель.

**Фазы 0–3 — это MVP** для закрытого теста. После фазы 3 приложение уже учит печатать на двух раскладках.

**Дизайн** можно подключить в любой момент после фазы 1. До этого интерфейс нейтральный и построен на токенах.
