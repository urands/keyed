# Продукт и функции

## Что это

KeyEd — бесплатное настольное приложение, которое учит слепой десятипальцевой печати: набору текста всеми пальцами без взгляда на клавиатуру.

Приложение само подбирает уроки под человека. Оно следит, какие клавиши даются хуже, и даёт на них больше практики. Новая клавиша открывается только тогда, когда уже открытые освоены.

Первая версия — это уроки и мотивация для двух раскладок: английской QWERTY (US) и русской ЙЦУКЕН. Рейтинги, аккаунты и другие раскладки появятся позже.

## Для кого

- Новички, которые никогда не учились печатать вслепую.
- Те, кто печатает быстро, но смотрит на клавиатуру или работает двумя–четырьмя пальцами.
- Те, кто уже печатает вслепую на одной раскладке и учит вторую.
- Те, кто хочет поднять скорость и точность.

## Принципы продукта

1. **Бесплатно для всех.** Без рекламы и платных функций.
2. **Работает без интернета и без регистрации.** Все данные хранятся на компьютере пользователя. Сеть нужна только для проверки обновлений.
3. **Точность важнее скорости.** Прогресс открывается за точный набор, а не за спешку.
4. **Короткие занятия каждый день.** Урок длится 1–2 минуты, дневная цель — 10–15 минут.
5. **Прогресс всегда виден.** После каждого урока понятно, что стало лучше и что тренировать дальше.
6. **Приложение не наказывает.** Пропущенный день или слабый урок не обнуляют достижения.

## Что входит в первую версию

| Группа | Функции |
|---|---|
| Обучение | Курс из этапов: буквы → заглавные → пунктуация → цифры. Клавиши открываются по одной. Перед новой клавишей — карточка «каким пальцем нажимать». |
| Адаптивные уроки | Текст урока собирается из слов и «псевдослов» только из открытых букв. Слабая («фокусная») клавиша встречается чаще. |
| Экран практики | Текст с курсором, скорость и точность в реальном времени, виртуальная клавиатура с цветными зонами пальцев, подсказка рук. |
| Результат урока | Скорость, точность, сравнение со средним, самые медленные и самые «ошибочные» клавиши, открытие новой клавиши. |
| Статистика | Графики скорости и точности, тепловая карта клавиш, календарь занятий, личные рекорды. Отдельно для каждой раскладки. |
| Мотивация | Дневная цель, серия дней с «заморозкой», достижения, личные рекорды, напоминания (по желанию). |
| Раскладки | Английская QWERTY (US) и русская ЙЦУКЕН. Прогресс по каждой ведётся отдельно. |
| Интерфейс | Русский и английский язык, светлая и тёмная тема. |
| Настройки | Целевая скорость, длина урока, единицы скорости, тип клавиатуры (ANSI / ISO), видимость клавиатуры и рук, звуки, размер шрифта, «меньше движения», дневная цель, экспорт, импорт и сброс данных. |

## Мотивация

В первой версии вся мотивация локальная, без сравнения с другими людьми.

### Дневная цель

- Цель задаётся в минутах активной практики: 5, 10, 15, 20 или 30. По умолчанию — 10.
- Считается только время набора. Паузы и простой не считаются.
- На главном экране и на экране практики виден прогресс к цели за сегодня.

### Серия дней

- День засчитывается, если дневная цель выполнена.
- За каждые 7 дней серии пользователь получает одну «заморозку». Хранить можно не больше двух.
- Если день пропущен и есть заморозка, она тратится автоматически, а серия сохраняется.
- Если серия всё же прервалась, приложение показывает лучшую серию и предлагает начать новую, без упрёков.

### Личные рекорды

- Лучшая скорость за урок, лучшая точность, самая длинная серия, самый продуктивный день.
- Сравнение «эта неделя против прошлой» по скорости, точности и времени практики.

### Достижения (стартовый набор)

| Достижение | Условие |
|---|---|
| Первый шаг | Завершён первый урок |
| Основная позиция | Освоены все стартовые клавиши основного ряда |
| Половина пути | Открыта половина букв раскладки |
| Весь алфавит | Освоены все буквы раскладки |
| Разгон | Скорость за урок достигла 100 / 150 / 200 / 250 / 300 зн/мин |
| Без единой ошибки | Урок с точностью 100% |
| Твёрдая рука | 10 уроков подряд с точностью не ниже 97% |
| Серия | Дневная цель выполнена 3 / 7 / 30 / 100 дней подряд |
| Время практики | Суммарно 1 час / 10 часов набора |
| Объём | Суммарно набрано 10 000 / 100 000 знаков |
| Две раскладки | Освоены стартовые клавиши во второй раскладке |

Список хранится как данные, его легко расширять.

### Напоминания

- Системное уведомление в выбранное время, если дневная цель ещё не выполнена.
- По умолчанию выключены. Включаются при первом запуске или в настройках.

## Что не входит в первую версию

- Аккаунты, синхронизация между устройствами.
- Рейтинги, таблицы лидеров, соревнования.
- Другие раскладки (Dvorak, Colemak, украинская, немецкая и т. д.).
- Свои тексты, импорт книг, режим для программистов.
- Веб-версия и мобильные приложения.
- Специальные функции для незрячих пользователей. «Слепая печать» здесь означает печать без взгляда на клавиатуру.

## Ограничения и договорённости

- **Код keybr.com не используется.** Он распространяется по лицензии AGPL. Алгоритм и данные в KeyEd свои. Мы берём идеи (адаптивные уроки, открытие клавиш), а не код.
- **Словари — только с открытой лицензией.** Источник и лицензия каждого словаря указываются в разделе «О программе».
- **Никакой телеметрии в первой версии.** Приложение ничего не отправляет в сеть, кроме запроса обновлений.

## Словарь терминов

| Термин | Значение |
|---|---|
| Слепая печать | Набор текста без взгляда на клавиатуру |
| Раскладка | Соответствие клавиш и символов: QWERTY, ЙЦУКЕН |
| Основной ряд | Средний буквенный ряд, где лежат пальцы: ASDF JKL; / ФЫВА ОЛДЖ |
| Зона пальца | Клавиши, которые нажимает один палец |
| Зн/мин (CPM) | Знаков в минуту — основная единица скорости для русского |
| WPM | Слов в минуту. 1 слово = 5 знаков, то есть WPM = зн/мин ÷ 5 |
| Точность | Доля знаков, набранных верно с первой попытки |
| Уверенность | Число от 0 до 1: насколько клавиша близка к целевой скорости и точности |
| Освоенная клавиша | Клавиша с уверенностью 1 при достаточном числе нажатий |
| Фокусная клавиша | Открытая клавиша с самой низкой уверенностью; в уроке встречается чаще |
| Псевдослово | Произносимое, но несуществующее слово из открытых букв |
| Серия | Число дней подряд, когда выполнена дневная цель |
